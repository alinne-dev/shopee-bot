# 🤖 Bot de Curadoria Inteligente (Telegram)

Sistema de curadoria automatizada para nicho de beleza e afiliados. O bot gerencia uma base de dados de produtos e realiza postagens agendadas de forma orgânica no Telegram, utilizando IA para gerar conteúdo natural.

> > **Status:** 🟢 Em produção (Deploy ativo na Railway) | **[Clique aqui para ver o Bot em ação no Canal](https://t.me/ofertasinteligentesag)**

## 🚀 O que este projeto faz
- **Gestão de Curadoria:** Processa uma lista de produtos estruturada em `produtos.json`, garantindo que o feed esteja sempre atualizado.
- **Automação Estratégica:** Realiza postagens agendadas em horários de pico, maximizando o engajamento.
- **IA de Conteúdo:** Utiliza a API da Groq para gerar legendas coloquiais e naturais, focadas em "indicação de amiga" em vez de vendas agressivas.
- **Infraestrutura Resiliente:** Sistema executado em container com lógica de reconexão automática e tratamento robusto de erros de API.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python
- **Integrações:** API do Bot do Telegram, API de IA (Groq)
- **Infraestrutura:** Railway (Deploy e monitoramento em nuvem)
- **Formato de dados:** JSON

## ⚙️ Como executar o projeto localmente
*(Adicione aqui os passos: 1. Clone o repo, 2. Instale as dependências com `pip install -r requisitos.txt`, 3. Configure as variáveis de ambiente do token do Telegram e da Groq, 4. Rode `python bot.py`)*
